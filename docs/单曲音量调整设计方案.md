# 单曲音量调整功能 — 设计方案

## 1. 需求

- 每首歌可设置一个独立的音量系数，播放时自动应用。
- 设置需持久化，下次播放同一首歌自动生效。
- 只影响软件内该歌曲的播放音量，**不改变设备系统音量**。

## 2. 音量模型（基准 0.9）

现有 `player.volume` 是全局音量（`defaultSetting.ts:23`，默认 1）。本功能是叠加在全局音量之上的**每曲系数**：

```
最终音量 = clamp(全局音量 × 基准 0.9 × 单曲系数, 0, 1)
```

- **基准 BASE = 0.9**：用户「单曲系数 100%」时，输出为全局音量的 90%，天然预留 10% 余量。
- 单曲系数范围 `0.1 ~ 2.0`（UI 显示 10% ~ 200%），默认 `1.0`（未设置过的歌）。
- 最终音量 clamp 到 `[0, 1]`：响度大的歌在系数放大时最多回到原始音量（不削波失真）；本身峰值低的安静歌可在 clamp 内获得真实放大。
- `react-native-track-player` 只暴露全局 `setVolume(level)`，`Track` 无 per-track volume 字段，因此每曲音量通过「切歌时重新调用 `setVolume`」在应用层模拟。

## 3. 数据模型

### 3.1 存储
独立键值缓存，不写入歌曲列表（列表项持久化路径只保存 `name/singer/source/interval/meta`，不适合塞入新字段）。

```
key:   '@music_volume__' + musicInfo.id
value: number   // 单曲系数，如 1 / 0.8 / 1.3
```

`musicInfo.id` 已含 source 前缀（`${source}_${songmid}`），天然唯一。

### 3.2 常量与 API

| 项 | 位置 |
|---|---|
| `musicVolume: '@music_volume__'` | `src/config/constant.ts` `storageDataPrefix` |
| `getMusicVolume(musicInfo): Promise<number>`（缺省 1） | `src/utils/data.ts` |
| `saveMusicVolume(musicInfo, volume)` | `src/utils/data.ts` |
| `removeMusicVolume(musicInfo)` | `src/utils/data.ts` |

该数据属于用户偏好而非缓存，**不纳入 MetaCache 清理**。

## 4. 播放流程

新增 `src/core/player/volume.ts` 作为音量统一入口，维护内存中的「当前曲系数」缓存：

- `applyMusicVolume(musicInfo)`：切歌时读取存储的系数，写入缓存并应用；用当前曲 id 做竞态保护，避免异步读取期间已切歌导致错用。
- `applyGlobalVolume(globalVolume)`：全局音量变化时，用缓存的当前曲系数重算并应用。
- `setCurrentVolumeFactor(factor)`：UI 实时拖动时更新缓存并应用。

挂载点：

1. **切歌**：`src/core/player/player.ts` `handlePlay()` 中，`playerInitial` 之后调用 `applyMusicVolume(当前歌曲)`（覆盖 `playListById`/`playList`/`playNext`/`playPrev`/恢复播放等全部路径）。
2. **初始化**：`playerInitial({ volume })` 先传入 `全局音量`（或 `全局 × 0.9`）作为兜底，随后由 `applyMusicVolume` 覆盖为叠加系数后的值，避免首曲短暂使用未叠加音量。
3. **全局音量变化**：`SettingVolume.tsx` 改为调用 `applyGlobalVolume(value/100)`，而不是直接 `setVolume(全局值)`。

## 5. 交互与 UI

- 在 **PlayDetail 设置弹窗**（`SettingPopup`）中新增「单曲音量」，与全局音量并列。
- 新增 `SettingMusicVolume.tsx`，复用 `src/components/common/Slider.tsx`：
  - 范围 10% ~ 200%，默认 100%，step 1。
  - 拖动中实时应用（`setCurrentVolumeFactor`），松手时持久化（`saveMusicVolume`）。
  - 提供「重置」按钮（回到 100%）。
  - 无当前播放歌曲时隐藏该控件。
  - 当前播放歌曲切换时重新读取并刷新显示。
- 注册到 `SettingPopup/index.tsx`。

## 6. 边界与异常

| 场景 | 处理 |
|---|---|
| 未设置过的歌曲 | 返回 1.0，等同原行为 |
| 同一 id 不同 source | id 已含 source，天然隔离 |
| `Download.ListItem` | 先归一化取其 `metadata.musicInfo` |
| 快速切歌 | 曲 id 竞态保护，丢弃过期结果 |
| 全局音量变化 | 按 `全局 × 0.9 × 系数` 重算 |
| 越界 | 系数 clamp `[0.1, 2]`，最终音量 clamp `[0, 1]` |
| 旧数据兼容 | 新前缀，无迁移；缺失默认 1.0 |

## 9. 测试要点

1. 设置单曲音量 → 停止 → 重播 → 音量保持。
2. 不同歌曲音量各自独立、互不影响。
3. 调整全局音量，单曲系数正确叠加。
4. 暂停恢复、上一首/下一首、列表点播均正确应用。
5. 超范围系数最终音量 clamp 到 1.0，无削波失真。
6. 设备系统音量全程不被改变。
